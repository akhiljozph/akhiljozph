# Project Overview

## Description
This repository (`akhiljozph`) hosts the personal portfolio website and professional engineering profile of **Akhil Joseph**, Senior Software Engineer and Google Certified Professional Cloud Developer.

The application is deployed directly to GitHub Pages at [https://akhiljozph.github.io/akhiljozph/](https://akhiljozph.github.io/akhiljozph/).

## Key Objectives
- **Professional Representation**: Highlight engineering expertise across Frontend Architecture, Backend Microservices, and Google Cloud Platform.
- **Performance & DX**: Provide an ultra-fast, zero-build static site with semantic HTML, modern CSS styling, interactive elements, and robust SEO.
- **Maintainability & AI Governance**: Utilize strict `.ai` documentation rules to maintain code quality, styling consistency, and AI-assisted development standards.
